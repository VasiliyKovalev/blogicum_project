## Блогикум
Блогикум - социальная сеть для публикации личных дневников.

### Описание
*  Зарегистрированные пользователи имеют возможность публиковать свои посты
*  При добавлении рецепта необходимо указать заголовок, описание, дату и время публикации. Есть возможность прикрепить изображение. Обязательно нужно выбрать месположение и категорию. 
*  Пополнять список местоположений и категорий может только администратор.

### Как запустить проект:
1. Клонировать репозиторий и перейти в него в командной строке:

```
git clone git@github.com:VasiliyKovalev/blogicum_project.git
```

```
cd blogicum_project
```

2. Создать и активировать виртуальное окружение:

```
python -m venv venv
```

```
source env/Scripts/activate
```

```
python -m pip install --upgrade pip
```

3. Установить зависимости из файла requirements.txt:

```
pip install -r requirements.txt
```

4. Выполнить миграции:

```
python manage.py migrate
```

5. Запустить проект:

```
python manage.py runserver
```

### После запуска проект будет доступен по адресу:
http://127.0.0.1:8000/
